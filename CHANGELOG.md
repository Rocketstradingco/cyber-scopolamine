# Changelog

All notable changes to Cyber-Scopolamine will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Windows CI coverage for Windows PowerShell 5.1 and PowerShell 7 parsing.
- PSScriptAnalyzer and Pester checks for pull requests.
- Contributor, security-reporting, licensing, and issue-reporting guidance.

## [1.0.0] - 2026-08-07

### Added

- Initial Windows installer for the local Ollama and aider coding workspace.
- GPU-aware model selection and model-store placement.
- Private pinned aider environment with Cyber-Scopolamine customizations.
- Chat, history, status, patch, intro, updater-control, and uninstall commands.
- Data-preserving uninstall behavior for user models and workspace files.
